Installation

Où la coller

Outlook (sur ordinateur)

Pour construisez@outlook.fr, sur outlook.com

  1. Ouvrez outlook.com, puis la roue dentée Paramètres.
  2. Comptes, puis Signatures.
  3. Nouvelle signature, nommez-la « Construisez » et collez.
  4. Choisissez-la pour les nouveaux messages ; créez la courte pour les réponses et transferts.
  5. Enregistrer.

Gmail (sur ordinateur)

Sur mail.google.com

  1. Roue dentée, puis Voir tous les paramètres.
  2. Onglet Général, rubrique Signature.
  3. Créer, nommez-la et collez.
  4. Choisissez-la pour les nouveaux e-mails et les réponses.
  5. Tout en bas : Enregistrer les modifications.

iPhone (app Mail)

Ouvrez cette page dans Safari

  1. Touchez Copier la signature (la courte passe mieux sur téléphone).
  2. Réglages, Apps, Mail, puis Signature.
  3. Effacez « Envoyé de mon iPhone » et collez.

Le logo s'affiche chez vos destinataires : il est chargé depuis construisez.fr. Certaines messageries masquent les images tant que le destinataire ne les a pas autorisées ; le texte reste lisible sans.

La version perso n'affiche pas votre adresse e-mail : vos destinataires la voient déjà comme expéditeur.

Si le bouton ne copie pas, sélectionnez la signature dans l'aperçu à la main, puis Ctrl + C (⌘ + C sur Mac).

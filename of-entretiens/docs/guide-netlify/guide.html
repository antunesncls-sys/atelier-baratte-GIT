OF ENTRETIENS

Mettre en ligne le site sur votre compte Netlify

Mode d’emploi pas à pas, avec l’offre gratuite de Netlify. Aucune compétence technique n’est nécessaire.

Durée : environ 30 minutesCoût : 0 €Version de novembre 2026

Ce qu’il vous faut

  • Le fichier of-entretiens-site.zip (fourni avec ce guide).
  • Une adresse e-mail pour créer le compte Netlify.
  • Les accès au nom de domaine ofentretiens.com (chez le bureau d’enregistrement : OVH, Gandi, IONOS…) ou au compte Netlify qui le gère aujourd’hui.

Ce que fait Netlify

  • Héberge le site et le sert en HTTPS (cadenas) gratuitement.
  • Reçoit les demandes des formulaires Estimation et Contact et vous les envoie par e-mail.
  • Applique les redirections des anciennes adresses du site (déjà prévues dans le zip).

€L’offre gratuite : ce qu’elle permet

L’offre Free de Netlify coûte 0 € et donne 300 crédits par mois, remis à zéro chaque mois. Le site les consomme ainsi :

ActionCrédits consommésPour ce site
Une mise en ligne (nouvelle version du site)15 créditsFaites-en peu : regroupez vos modifications.
Données envoyées aux visiteurs20 crédits par GoUne visite complète de l’accueil ≈ 0,8 Mo.
Requêtes (chargement des fichiers)2 crédits par 10 000Environ 25 requêtes par visite.
Formulaires (Estimation, Contact)0 créditGratuits et illimités.

En pratique : avec 4 mises en ligne dans le mois, il reste de quoi servir environ 10 000 visites, ce qui est très au-dessus de la fréquentation habituelle d’un site d’entreprise local.

À savoir L’offre gratuite a une limite stricte : si les 300 crédits sont épuisés, Netlify met le site en pause (page « Site not available ») jusqu’au mois suivant, et il n’est pas possible d’acheter des crédits sans passer à une offre payante. Jetez un œil à la consommation une fois par mois (voir l’étape 8).

1Créer le compte Netlify

  1. Allez sur netlify.com et cliquez sur Sign up.
  2. Inscrivez-vous avec votre adresse e-mail (ou un compte Google), puis confirmez l’e-mail reçu.
  3. Si Netlify vous demande de choisir une offre, prenez Free.
  4. Donnez un nom à votre équipe, par exemple OF ENTRETIENS.

2Préparer les fichiers

Netlify demande un dossier, pas un fichier zip. Faites un clic droit sur of-entretiens-site.zip puis Extraire tout… (Windows) ou double-cliquez dessus (Mac). Vous obtenez un dossier qui doit contenir directement le fichier index.html :

of-entretiens-site/ ├── index.html ← doit être ici, pas dans un sous-dossier ├── carottage-urgence-montfermeil/ ├── corvoyage-montfermeil/ ├── estimation/ contact/ realisations/ … ├── assets/ ├── _redirects _headers netlify.toml └── sitemap.xml robots.txt
Fichiers invisiblesLes fichiers _redirects et _headers sont indispensables (redirections des anciennes pages et sécurité). Ne supprimez rien dans ce dossier.

3Mettre le site en ligne

  1. Connecté à Netlify, ouvrez la page Projects de votre équipe.
  2. Tout en bas de la page se trouve une zone « glisser-déposer ». Faites glisser le dossier préparé à l’étape 2 dans cette zone.
    (Autre possibilité : l’adresse app.netlify.com/drop.)
  3. Après quelques secondes, le site est en ligne à une adresse provisoire du type nom-au-hasard-12345.netlify.app. Cliquez dessus pour vérifier.
  4. Pour une adresse plus lisible : Project configuration → Change project name → par exemple ofentretiens-site.

4Activer les formulaires de devis

Sans cette étape, les demandes envoyées depuis le site ne vous parviennent pas.

  1. Dans le projet, ouvrez Forms puis cliquez sur Enable form detection.
  2. Remettez le site en ligne une fois pour que Netlify repère les formulaires : Deploys → faites glisser à nouveau le même dossier dans la zone en bas de la page.
  3. Retournez dans Forms : les formulaires estimation et contact apparaissent.
  4. Forms → Submission notifications → Add notification → Email notification : indiquez mike.ofentretiens@gmail.com. Choisissez « tous les formulaires » (ou ajoutez une notification pour chacun des deux).
  5. Faites un essai : remplissez le formulaire de la page /estimation/. Vous devez arriver sur la page « Merci » et recevoir l’e-mail (pensez à regarder dans les indésirables la première fois).

5Brancher le nom de domaine ofentretiens.com

Situation actuelle Aujourd’hui, ofentretiens.com est relié au compte Netlify de votre prestataire. Un domaine ne peut être utilisé que par un seul compte : il faut d’abord le libérer dans l’ancien compte. Le site peut être indisponible de quelques minutes à quelques heures pendant la bascule : faites-la un soir ou un week-end.

a) Libérer le domaine dans l’ancien compte (à faire par votre prestataire)

  1. Dans l’ancien projet : Domain management → à côté de chaque domaine, Options → Remove domain.
  2. Dans l’équipe : Domains → ofentretiens.com → supprimer la zone DNS (si le domaine utilise « Netlify DNS »).

b) Ajouter le domaine dans votre compte

  1. Dans votre projet : Domain management → Add a domain → saisissez www.ofentretiens.com. Netlify ajoute automatiquement ofentretiens.com. Gardez www.ofentretiens.com comme domaine principal (c’est l’adresse utilisée partout dans le site).
  2. Netlify vous propose ensuite de régler le DNS. Deux possibilités :

Option 1 — Netlify DNS (le plus simple)

Acceptez « Netlify DNS ». Netlify affiche 4 serveurs de noms (du type dns1.p01.nsone.net). Chez votre bureau d’enregistrement, remplacez les serveurs de noms du domaine par ces 4 adresses. Netlify gère ensuite tout le reste.

Option 2 — garder le DNS chez votre bureau d’enregistrement

Créez ces deux enregistrements dans la zone DNS du domaine :

A  @ → 75.2.60.5
CNAME  www → votre-projet.netlify.app

Remplacez « votre-projet » par l’adresse de l’étape 3. Si votre fournisseur propose ALIAS/ANAME, préférez apex-loadbalancer.netlify.com à l’adresse A.

c) Activer le HTTPS (cadenas)

Une fois le DNS pris en compte (de quelques minutes à 24 heures), allez dans Domain management → HTTPS. Le certificat gratuit Let’s Encrypt est créé automatiquement ; sinon, cliquez sur Verify DNS configuration puis sur le bouton de création ou de renouvellement du certificat.

6Vérifier que tout fonctionne

  • https://www.ofentretiens.com s’affiche avec le cadenas, et ofentretiens.com (sans www) y renvoie.
  • Les pages de service s’ouvrent depuis le menu Services, sur ordinateur et sur téléphone.
  • Une ancienne adresse comme /corvoyage.html renvoie bien vers /corvoyage-montfermeil/.
  • Le bouton Appeler lance bien un appel depuis un téléphone.
  • Une demande test envoyée depuis /estimation/ et depuis /contact/ arrive par e-mail.
  • Une adresse qui n’existe pas affiche la page « Cette page n’existe pas ».

7Mettre à jour le site plus tard

  1. Récupérez le nouveau zip fourni par votre prestataire et extrayez-le (comme à l’étape 2).
  2. Dans le projet : Deploys → faites glisser le dossier dans la zone en bas de la page.
  3. La nouvelle version remplace l’ancienne en quelques secondes. En cas de souci, dans Deploys, cliquez sur une version précédente puis sur Publish deploy pour revenir en arrière (sans consommer de crédits).
Économiser les créditsChaque mise en ligne consomme 15 crédits : regroupez vos changements plutôt que de publier plusieurs fois par jour.

8Surveiller la consommation

Une fois par mois, ouvrez la page de facturation et d’utilisation de votre équipe (rubrique Billing / Usage) pour voir les crédits restants. Si vous approchez des 300 crédits, évitez les mises à jour jusqu’au mois suivant ou envisagez une offre payante.
